# Mohd. Jahidul Islam — Professional Portfolio

A responsive, dark industrial-style portfolio built with Next.js App Router, React, TypeScript and custom CSS.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Before publishing

1. Replace `public/resume.pdf` with the latest approved CV.
2. Confirm the phone number and email are still correct.
3. Update the metadata URL in `app/layout.tsx` from `https://example.com` to the final domain.
4. Deploy to Vercel or another Next.js host.

## Content accuracy notes

- Experience dates and project details are taken from the supplied CV.
- The portfolio describes SCADA monitoring and PLC interfaces; it does not claim DCS experience.
- UF appears in the CV skills list, but no specific UF project role or hands-on UF experience is claimed.
- The CV lists project capacities as supplied; verify the units and project naming before public launch.
- The portfolio uses the CV's listed Riyadh location and contact details. Confirm they are current before publishing.
